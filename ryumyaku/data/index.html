OPEN DATA — 龍脈マップ

場所のデータと、その作り方。

iPhone アプリ「龍脈マップ」に入れている、神社・お寺・自然の場所のデータです。全国の有志がつくる地図 OpenStreetMap から取り出して整えたものなので、同じオープンなライセンスで、データそのものと作り方を公開しています。

ライセンス

場所のデータ（ryumyaku-places）は、OpenStreetMap のデータから取り出して整えた部分を含むため、Open Database License（ODbL）1.0 で提供します。

© OpenStreetMap contributors

source 列が「Wikidata (CC0)」の行は、OpenStreetMap に無く、Wikidata（CC0）から加えた場所です。

このデータを使って地図やアプリなどを公開するときは、「© OpenStreetMap contributors」と、ODbL のデータであることを示してください。このデータに手を加えたデータベースを公開・配布するときは、同じ ODbL で提供してください。くわしくは ODbL の本文と、OpenStreetMap の著作権とライセンスのページをご覧ください。

Wikidata の補足（ryumyaku-facts）は、Wikidata（CC0）から集めた情報です。

龍脈マップはこのデータベースをアプリに入れて配っているため、ODbL（4.6）にしたがって、データベースそのものと、その作り方をここで公開しています。アプリのデータを作り直したときは、新しい版をここに足します。

作り方

  1. 取り出す：OpenStreetMap の日本の抽出（Geofabrik）から、神社・お寺・滝・巨樹・湧き水・岩・山・洞窟の印がついたものを取り出します。
  2. 分けて、まとめる：種類に分け、社殿や堂の一部として登録されたものを外し、点と輪郭の二重登録をまとめます。お寺は名前のあるもの（道ばたの地蔵や石仏などの小さなものは入れていません）、山は名の知られたもの（Wikipedia・Wikidata の項目があるもの）を入れています。
  3. 照らし合わせる：Wikidata の社寺・名所と重ね、OpenStreetMap にある場所には読みとウィキペディアの項目名を足します。OpenStreetMap に無い場所は、「位置は目安」の印をつけて加えます。
  4. 読み取る：神社の名前から「系統」（お稲荷さん・八幡さま など）を読み取ります。
  5. 書き出す：アプリに入れる形にまとめ、同じ中身を、このページの CSV と TSV に書き出します。

スクリプトを動かすには、Geofabrik の日本の抽出（japan-latest.osm.pbf）と、Python のライブラリ（pyosmium）が要ります。くわしくは ZIP の中の説明書きをご覧ください。

そのほかの出どころ

次のものは、アプリの中で使っていますが、このページの公開データには入っていません。

  • 地図と地形：国土地理院の地理院タイル（標高タイル・淡色地図）を加工して作成しています。アプリが、見ている範囲だけその場で読み込みます。龍脈の線は、この標高から計算しています。
  • ウィキペディア：「ここの読み方」で読める冒頭の文は、押したときにその場で日本語版ウィキペディアから読み込み、出典とライセンス（CC BY-SA 4.0）を添えて出しています。公開データには、項目名（wikipedia_ja 列）だけが入っています。

ご注意

  • 位置や名前は、もとのデータのとおりです。まちがいを見つけたら、OpenStreetMap で直していただくと、次の版に入ります。
  • 系統は名前からの推定です。まつる神さまやご利益は、神社ごとに異なります。
  • このデータは、場所を探す手がかりとして作ったものです。境内や自然の場所を訪ねるときは、それぞれの決まりと安全にご注意ください。

データについてのお問い合わせは、お問い合わせフォーム（「その他・取材・コラボ」）から、本文のはじめに「龍脈マップ」とお書きください。
